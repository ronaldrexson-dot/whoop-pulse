Strap setup

  1. In the WHOOP app: More → Device settings → Heart Rate Broadcast → On. Keep it on while you use Pulse.
  2. On iPhone, open this page in Bluefy (Safari has no Bluetooth access for web pages).
  3. Tap Connect strap and pick the WHOOP from the list.
  4. Keep Pulse open and the screen on. iOS pauses Bluetooth for web pages in the background.
